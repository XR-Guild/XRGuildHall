# 🏛️ XR Guild Hall — Immersive Production Punch List

Shared production tracker for the **XR Guild Hall** immersive build. This is the source of truth for what needs to get made. Volunteers: find something that fits your skills and claim it.

**Repo:** https://github.com/LightLodges/XRGuildHall

---

## How to use this list

- **Progress** is tracked with the checkboxes below — tick an item when it ships.
- **To claim a task**, replace `@open` next to it with your GitHub handle so the team knows who's on it.
- **Categories** map 1:1 to suggested issue labels and Project board columns (see [Turning this into issues](#turning-this-into-issues)).
- **Questions on a task?** Open an issue, tag it with the matching category label, and link back here.

## Turning this into issues

For real assignment and a Project board, spin each item into an issue. Suggested label scheme (one per category, so the board filters cleanly):

| Label | Category |
|---|---|
| `architectural` | Architectural |
| `production-spaces` | Production Spaces |
| `interactive` | Interactive Elements |
| `content` | Content & Reference |
| `gardens` | Gardens |

A maintainer with repo access can bootstrap all labels and issues with the [GitHub CLI](https://cli.github.com/) — ask in the repo and someone can run the setup script.
